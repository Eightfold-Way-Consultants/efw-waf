# www-redirect host list — the maintainable source of truth.
#
# Each line is a DB101/HB101 state-estimator host (public or preview). The generator
# (generate.py) emits, for each: a cert SAN `www.<host>`, an ACM DNS-validation entry in
# the host's zone, a CloudFront alias, and a Route53 CNAME `www.<host>` -> the redirect dist.
# The dist runs one generic strip-`www` 301, so www.<host> -> https://<host>/.
#
# WHY: DB101's audience (older/less-technical users) and our clients (told to test on
# preview-<state>) reflexively type "www." in front of a host. Because HSTS force-upgrades
# to HTTPS and *.db101.org (a single-label wildcard) does NOT cover the double-label
# www.<state>.db101.org, they hit a non-bypassable cert error today. This makes them work.
#
# ADD A NEW STATE: add its public + preview (+ -es) host line(s) below, run `generate.py`,
# then `deploy-stack.ps1 www-redirect`. (SANs are immutable, so the deploy replaces the ACM
# cert, waits for issuance, and swaps the dist to it — all in one run.)
#
# Do NOT add: single-label www hosts (www.db101.org — real site, already *.db101.org-covered),
# eightfoldway.com, or vets101.org. Only db101.org + hb101.org state leaves.
